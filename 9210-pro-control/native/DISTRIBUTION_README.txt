9210 Pro Control v@VERSION@（构建 @BUILD@）· @PLATFORM@

安装与打开
1. 解压，将“9210 Pro Control.app”拖入“应用程序”，或放在任意本地文件夹。
2. 双击打开。无需安装 Python、ADB、Xcode，也不需要原项目目录。
3. 这是供内部试用的本地签名应用，尚未经过 Apple Developer ID 签名和公证。
   若系统拦截，请确认收到的是可信来源的软件后，在“系统设置 → 隐私与安全性”
   查看该应用的“仍要打开”选项。无需关闭系统整体安全保护。
4. 首次连接需要在系统提示中允许蓝牙；先在原平板上断开工作站连接。

兼容范围
• 当前压缩包：@PLATFORM@。
• 最低 macOS 14.0；不是 Windows 或安卓软件。
• 在“苹果菜单 → 关于本机”查看芯片：Apple M 系列选 AppleSilicon 包；
  Intel 处理器选 Intel 包。Universal 包（如有提供）适用两种芯片。
• 开发机为 Apple Silicon / macOS 26。Intel 及 macOS 14/15 尚未实机验证。

连接工作站
默认打开软件会查找 XLBLE（也识别 XBLE），成功后记住该设备。
在“连接…”中可以关闭启动自动连接，或点“更换设备”选择其他工作站。
更换并成功连接后，新设备成为默认；连接本身不会自动复位或运行程序。
连接成功会切换到实机模式，也可以手动切回模拟模式检查程序。

迁移程序与参数
此包自带初始参考方案和参数，不包含发送者当前的自定义工作区、连接记忆或日志。
若要沿用发送者当前的程序、耗材、速度及板位参数：
1. 发送者在软件中点“文件 → 导出工作区…”，将导出的 JSON 另行发送。
2. 接收者点“文件 → 导入工作区…”，选择该 JSON。
导入会替换接收者当前工作区，并在本地备份原工作区。
导出文件包括全部程序、参数及已删除程序，发送前可自行检查内容。
不同工作站的板位坐标、装卸头高度和液体标定应按实际设备配置。

数据保存
用户数据自动保存在：
~/Library/Application Support/9210 Pro Control/
workspace.json 保存程序与参数；bluetooth.json 保存连接偏好。
通信与动作记录也保存在该文件夹。更换应用文件不会清除这些用户数据。

功能说明
支持程序编排、装卸头、吸排液、混匀、循环、手动操作及分段下降吸液。
程序侧栏显示名称和右对齐的量程，可拖动排序，或拖入、拖出一级文件夹。
单击文件夹标题可选中；点击左侧箭头或双击标题可展开或折叠，拖动标题可调整文件夹顺序。
按 ⌘ 点选或按 ⇧ 连选多条，再拖其中任意一条即可整组移动；顺序和归属自动保存。
步骤表中双击有效行运行单步；复位／单步运行期间可以选择步骤和修改程序参数，
当前动作使用启动时的快照。复位成功后顶部中央提示“复位完毕”，3秒后消失。
分段下降吸液：先按正常速度完成起始 Z 定位，再逐段下降和吸液；两轴交替动作。
此分发包已完成构建和离线检查；具体工作站的机械速度、位置和体积仍需实际核验。
