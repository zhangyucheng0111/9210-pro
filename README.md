# 9210 Pro Mac 控制软件

在Mac上自由编排装头、卸头、吸液、排液、混匀、震荡、等待和循环。两列、四列Split / Pool保留为参考程序，可以从空白建立任意流程。

双击 **[Start_Mac.command](Start_Mac.command)**，或打开 **[9210 Pro Control.app](Mac/9210%20Pro%20Control.app)**。默认进入模拟模式；模拟运行生成指令和记录，供检查步骤、参数与顺序。实机动作需要切换到设备模式并连接工作站。

当前主应用为 **v1.0.0，构建37**。单击文件夹标题可选中，点击左侧箭头或双击标题可展开与折叠。详见 [1.0 发布说明](mac-review-20261115/UPDATE_1.0.0.md)。

v0.8.7 继续在主应用 `Mac/9210 Pro Control.app` 与 `9210-pro-control/native/Sources` 开发。程序步骤采用 AppKit `NSTableView` 原生可调列宽表格，依次显示顺序、动作与位置、体积、补充参数；主要体积突出，适用的混匀次数、前／后空气、吹样和混匀后吸液集中在最后一列，过长省略、悬停查看完整内容。右侧参数按体积、速度、位置孔位、辅助功能、抬升设置排列，以分隔线区分；自定Z随位置设置，混匀的后吸液、补偿和液体放在辅助功能。程序列表统一行高与分隔；可在表格内拖动步骤调整顺序，多选拖动保留所选步骤的相对顺序，支持撤销／重做。辅助功能直接在右栏添加、修改数值或移除。手动页左侧选择功能、右侧设置参数与执行；速度页左选类型、右改10档，设备参数左选分组、右改字段，资料页明确显示所选记录与详情。板位页把坐标编辑、移到板位、当前位置填入与四轴点动集中在顶部“定位与标定”，宽时并排、窄时上下紧邻，耗材和预设随后。各编辑页提供对应保存按钮和实际写入状态；v0.8.9起板位位置须明确保存，其余修改继续自动保存；底栏集中显示执行状态与消息。本版验收状态见更新说明。详见 [本版更新](mac-review-20261115/UPDATE_0.8.7.md)、[设计规则](DESIGN.md) 和 [Mac使用说明](9210-pro-control/native/README.md)。

v0.6.1已通过arm64构建、签名及[独立界面验收](9210-pro-control/native/Tests/ui-verification-0.6.1.json)。当时核查界面功能、参数计算、最终发送字节与执行回执的对应关系：核心7,838项、速度2,858项、指令240项及模型126项通过；原169个动作全部可编译，121条历史指令精确匹配保留。详见 [v0.6.1更新说明](mac-review-20261115/UPDATE_0.6.1.md)。

- 程序页保留通用速度、步骤多选复制、批量改孔、矩形选孔、单层循环、撤销重做、导入导出和可拖动栏宽。双击有效步骤行运行该行，多选时也只运行双击行；表头、空白处不触发运行。可拖动单步或多选步骤调整顺序，保留相对顺序并支持撤销／重做；现有“复制所选”与“复制”按钮继续使用。步骤孔位直接点击孔图，保留起点范围和孔数；“批量改行列”仍可使用。
- 板位组合设置20／1000 µL量程，程序与手动操作共同沿用，不再重复选量程。板位XYZ与其他位置参数先保留为草稿；读取当前位置不改正式坐标，只有“保存此板位位置”才合入工作区。
- “手动操作”页按枪头操作、移液操作和设备分组，可选择插枪头、卸枪头、吸液、放液、混匀、分段下降吸液或复位；右侧独立选择台面、动作板位／孔位并执行，量程随板位组合，无需新建程序；2排对应A11→H12，4排对应A9→H12（12列枪头盒）。台面选择旁的“通用速度…”统一设置手动X／Y／Z、装头第二段、卸头和吹样；卸头参数会写入指令，退头机构的实际调速效果待实测。
- 已修复小数悬停丢失、震荡模块0未沿用全局配置，以及非法后吸空气Z位置。错误板号、孔距、动作类型、辅助段与速度配置会在发送前报错。
- 速度按使用位置生效：程序XYZ／装卸头／吹样使用程序保存值，手动装卸头及普通吸／放／混匀的XYZ、吹样使用手动通用速度的独立保存值，吸／放及混匀液体档位读取对应速度表。手动板位定位读取设备定位速度，分段下降吸液使用其面板专用速度；普通点动命令只包含方向和距离。
- Z轴保留非负和Int32编码范围，允许现有100mm以上板位。“移动到所选板位”发送该板位XY、Z=0；板位移动与Z回零不会被旧XY维护限位误拦截。普通X／Y／柱塞点动继续检查各自配置限位。

孔位坐标沿用原安卓计算：非384耗材的行方向也使用 `XSpacing`；`YSpacing` 用于384分支。液体补偿的算法与作用范围见更新说明。

当前支持12类日常指令，详细字段、历史帧及功能缺口见 [指令结构核查](mac-review-20261115/COMMAND_AUDIT_0.6.1.md)。普通复位沿用已有本机完成回执和零点回读证据的20字节短帧；原APP的“卸头复位”“排液后卸头复位”尚未开放。设备维护写入和固件升级也未开放。
